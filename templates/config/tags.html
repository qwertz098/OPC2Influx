Central Tags

What tags are for. A tag is a label (key = value) that InfluxDB stores with every value of a signal, e.g. machine=TG-01. Tags are indexed, so in InfluxDB queries and dashboards (e.g. Grafana) you can filter and group by them: show all signals of one machine, or compare the same signal across several machines that write into one bucket.

  • Static: a fixed value, e.g. site, machine or line name.
  • Dynamic: the value is read from another OPC UA node next to the signal, e.g. the recipe or batch name, and changes with it.
  • Per signal: switch tags on or off with the small tag buttons in the Tags column on the Subscriptions page. Default Active switches the tag on for signals subscribed from now on.

Tags only go to InfluxDB; the SQLite files have no tags. Tags that apply to every signal of a server can also be set on the Servers page (Static Tags).

Relative path syntax (for dynamic tags):
  • ./tagName — sibling of the subscribed node (same parent)
  • ../tagName — uncle node (one level up, then descend)
  • ../../Sub2/tagName — go up 2 levels then descend into Sub2/tagName
Dynamic tag values are resolved once on first poll and cached until the subscription is modified.
