Stale Value Watchdog

Alerts when a subscribed signal's value does not change within the selected window — catches a signal that's "frozen" even though the server and subscription are otherwise fine. A full server outage is already covered by the Watchdog above; use Suppress when server disconnected to avoid a duplicate alert in that case.
