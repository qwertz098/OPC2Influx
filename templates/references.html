Each time the condition becomes true (after the delay) one event is written: the rows before it, the trigger row with the comment "Auto: …" and the rows after it, all with the same event number. At most 300 rows before and 300 after.

Changing the signals later keeps existing rows as they were; columns of removed signals stay visible as long as rows have values for them.
